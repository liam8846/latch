# Latch 光照貼圖

使用 `cargo run --locked --example bake_study` 重新生成五張貼圖。程式以各區固定幾何與簡化的遮擋物追蹤一次漫反射，並計算接觸處的環境遮蔽。每像素採樣 64 條射線。

- `study-moon.png` 和 `study-lamp.png` 對應午夜書房桌燈關閉與開啟。
- `foyer-night.png` 和 `foyer-lit.png` 對應老宅玄關關燈與開燈，涵蓋南北門廊。關燈時保留月光，夜光暗記由遊戲獨立顯示。
- `signal-room.png` 涵蓋潮汐信號室和岸邊出口，烘焙固定的冷暖光源。反光鏡、光束、接收窗與出口閘門由遊戲即時更新。

圖集由 Latch 原創場景配置生成。各圖集使用獨立的第二組 UV。活動家具和燈具的直射光影由遊戲即時繪製。修改固定佈置或光源後，請重新執行烘焙。
